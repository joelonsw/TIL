## Claude Plugin
**개요**
- Claude Code에 기능 묶음을 한번에 설치하는 패키지

**요소**
- 스킬: 특정 작업을 어떤 절차로 할지 Claude가 적어둔 매뉴얼 (migrate 스킬 - 업무 프로세스)
- MCP: Claude가 외부 API 호출할 수 있게 해주는 통로
- 스크립트/참고 문서: 스킬이 쓰는 도구와 지식. (.md 파일, .py 파일)
- 에이전트/훅: 특정 역할을 맡는 보조 Claude, 자동 실행 규칙

**마켓플레이스**
- 플러그인 목록(카탈로그)를 담은 git 저장소
  - https://github.com/anthropics/claude-plugins-official

## Function Calling
**표준 Function Calling**
1. 요청: `messages + tools=[{type:"function", function:{name, description, parameters(JSON Schema), strict: true}}]`
    - tool_choice = "auto"
2. 응답: assistant 메시지에 tool_calls=[{id, name, arguments}]
3. 앱이 함수를 실행
4. 요청: 이전 `messages + assistant(tool_calls) + {role:"tool", tool_call_id, content: 결과}`
5. 응답: 최종 답변 또는 tool_calls 또 요청 -> 필요할 때까지 반복
- 특징)
  - 도구 정의가 tools 파라미터로 들어감
  - 부를지말지를 모델이 정함 (`tool_choice=auto`)
  - 인자는 함수별 JSON Schema로 정의. (strict를 켜면 필수값/타입/enum 강제)
  - 결과는 `role:"tool"` + `tool_call_id` 이력에 이어붙임
  - 결과보고 추가 조회 필요하면 루프 다시돔

**API를 호출하도록 Function Calling**
- 함수 목록, 설명, 인자 설명은 `required_tools`의 description 문자열 하나에 이어 붙여 전달
```
{ "answerable": bool, "refusal_reason": ..., "core_answer": ..., "final_answer": ...,
  "required_tools": [ { "name": enum[함수명들],
                        "arguments": [ {"key": enum[모든 함수 인자 key의 합집합], "value": string} ] } ] }
```
```
1차: 답변 전략 × LLM 호출
     → 답변 + answerable + required_tools 가 한 JSON 으로 동시에 나옴
   ↓
코드 게이트: answerable=false 및 required_tools 확인
   ↓
코드레벨에서 HTTP 호출 (DB의 url/method/paramLocation 으로 조립)
   ↓
2차: 대화를 잇지 않고 System + Human(["조회 결과"] 블록 + 1차 검색 문서 + 질문) 으로 새로 호출
 ```
