## Function Calling
- **개요**
  - LLM은 직접 실행하지 않는다. 
  - "이 함수를 이 인자로 호출하고 싶다" 라는 구조화된 json 출력
    - 실행은 백엔드 자체에서 진행
    ```
    기존 RAG:   질문 → [코드가 무조건 retrieve] → 컨텍스트 주입 → 생성
    Tool 기반:  질문 → 모델이 판단 → "search_policy(query=...) 호출해줘" → 백엔드 실행 → 결과 반환 → 모델이 판단 → 답변 or 추가 호출
    ```
  - 언제, 무엇을, 어떤 쿼리로 검색할지 "모델"이 결정

- **예시 및 설명**
```python
import anthropic
client = anthropic.Anthropic()

tools = [{
    "name": "search_policy",
    "description": "환불/배송 정책 문서에서 관련 조항을 검색한다.",
    "input_schema": {
        "type": "object",
        "properties": {
            "query": {"type": "string", "description": "검색 쿼리"},
            "doc_type": {"type": "string", "enum": ["refund", "shipping", "cs"]}
        },
        "required": ["query"]
    }
}]

messages = [{"role": "user", "content": "환불 시 배송비를 환급받을 수 있나요?"}]

while True:
    resp = client.messages.create(
        model="claude-sonnet-4-5", 
        max_tokens=1024,
        tools=tools, 
        messages=messages
    )
    if resp.stop_reason != "tool_use":
        break
    messages.append({"role": "assistant", "content": resp.content})
    for block in resp.content:
        if block.type == "tool_use":
            result = my_hybrid_search(block.input["query"])
            messages.append({
                "role": "user",
                "content": [{"type": "tool_result",
                             "tool_use_id": block.id,
                             "content": format_chunks(result)}]
            })
```
