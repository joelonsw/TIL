## Claude Plugin
**개요**
- Claude Code에 기능 묶음을 한번에 설치하는 패키지

**요소**
- 스킬: 특정 작업을 어떤 절차로 할지 Claude가 적어둔 매뉴얼 (migrate 스킬 - 업무 프로세스)
- MCP: Claude가 외부 API 호출할 수 있게 해주는 통로
- 스크립트/참고 문서: 스킬이 쓰는 도구와 지식. (.md 파일, .py 파일)
- 에이전트/훅: 특정 역할을 맡는 보조 Claude, 자동 실행 규칙

**마켓플레이스**
- 플러그인 목록(카탈로그)를 담은 git 저장소
  - https://github.com/anthropics/claude-plugins-official
- 핵심은 `.claude-plugin/marketplace.json`
  - 여기에 플러그인 이름 + 해당 플러그인의 위치가 저장됨
    ```json
    {
      "plugins": [
        {
          "name": "adobe-for-creativity",
          "description": "Harness Adobe's creative AI-powered tools to edit images, automate design workflows, and bring creative visions to life — from background removal to vectorization and professional retouching.",
          "author": {
            "name": "Adobe"
          },
          "category": "design",
          "source": {
            "source": "git-subdir",
            "url": "https://github.com/adobe/skills.git",
            "path": "plugins/creative-cloud/adobe-for-creativity",
            "ref": "main",
            "sha": "acb6d76475e6c522a5b109d2df7c8a794ee74ea7"
          },
          "homepage": "https://github.com/adobe/skills/tree/main/plugins/creative-cloud/adobe-for-creativity"
        }
      ]
    }
    ```
- marketplace add -> plugin install
